# Security recommendations index

All recommendations in this hub use **synthetic example data only**. This is
a training repository — nothing here reflects a real Contoso customer
environment.

Adding a new recommendation? Copy [`_TEMPLATE.md`](_TEMPLATE.md) into the
matching category folder, fill it in, and add a row below in the same pull
request. See [`../../LAB.md`](../../LAB.md) for the full step-by-step
workflow.
